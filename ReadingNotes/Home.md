## Workflow
1. Keep the book overview, reading progress, and chapter notes in its book note.
2. Move substantial ideas into `Concepts` and link them from the book.
3. Store exercises, experiments, and implementation notes in `Experiments`.
4. Put images and PDFs in `Attachments`.

Create new book notes in `Books` using [[Book Template]]. In Obsidian, run **Templates: Insert template** from the command palette.

Folders are ordinary directories; links work across them. The library Base displays book notes using their properties.
